## Featured project

**[offline-sync](https://github.com/aksansz/offline-sync)**: a sync API and TypeScript client for apps that keep working offline. Retries never apply a change twice, concurrent edits come back as conflicts instead of overwriting each other, and the change feed never skips a write. A chaos demo in CI proves it against the real stack while one request in three fails. .NET 10, PostgreSQL, TypeScript.
